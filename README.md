# Internet Terminology Website

This project is a multi-page website designed to explain and elaborate on key Internet terminology concepts. Each term is presented on its own HTML page with clear explanations, interlinked navigation, and supporting visual aids. The goal is to provide a structured, accessible learning resource aligned with coursework requirements.

# Covered Topics
- World Wide Web (WWW)
- Transmission Control Protocol / Internet Protocol (TCP/IP)
- Web Browsers
- Web Servers
- Uniform Resource Locators (URLs)
- Domain Name Server (DNS)
- Hypertext Transfer Protocol (HTTP)
- Intranet
- Extranet
- Multitier Architecture
- File Transfer Protocol (FTP)
- Hypertext Mark-up Language (HTML)
- Web 1.0, Web 2.0, Web 3.0, Web 4.0

# Features
- Individual HTML pages for each terminology term
- Consistent navigation bar across all pages (HTML-only, no CSS styling)
- Visual aids included on every page to support explanations
- Interlinked pages for seamless navigation
- Organized project assets with all images stored in a dedicated `images/` folder
